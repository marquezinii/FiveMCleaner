FiveMCleaner includes the .NET runtime and every dependency required to run the
application on Windows 10 version 2004 (build 19041) or later and Windows 11 on
x64-compatible systems. No additional runtime, script, or package is downloaded
during installation.

Setup runs per user and does not request administrative access. FiveMCleaner
asks for elevation only when a selected optimization needs to change a protected
Windows setting.

Settings, logs, backups, and downloaded updates live in
%LOCALAPPDATA%\FiveMCleaner, outside the install folder. During uninstall you
choose whether to keep that data; the default is to preserve it.

The desktop shortcut is selected by default. Start with Windows is off by
default and can be enabled if you want it. Both can be changed later and are
removed during uninstall.

Later updates are offered inside the app after you confirm them. You usually do
not need to download this installer again.

Download the installer only from:
https://marquezinii.github.io/FiveMCleaner/
or the official release page:
https://github.com/marquezinii/FiveMCleaner/releases

Before running it, verify the published .sha256 sidecar:
  (Get-FileHash .\FiveMCleaner-Setup-*-win-x64.exe -Algorithm SHA256).Hash
